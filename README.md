# 性感风格穿搭解说智能体（抖音/TikTok）落地方案

> 目标：你把一个参考视频发给智能体后，系统可以自动分析「文案结构、音乐节奏、视频节奏」，再自动搜集同类素材并生成优化版穿搭解说短视频脚本与剪辑指令，形成高吸引力的内容生产流水线。

---

## 0. 先说边界（必须做）

在做这类内容前，建议你把这 4 条写进系统规则：

1. **版权合规**：只使用你有授权的视频/音乐素材（原创、商用授权、平台可用曲库）。
2. **平台合规**：避免擦边、过度性暗示、低俗导向，遵守抖音/TikTok 社区规范。
3. **人物权利**：如果是实拍人物，确保肖像授权；AI 生成人物也要避免冒充真人。
4. **广告与导购合规**：涉及品牌推荐、带货时，遵守广告标识和本地监管要求。

---

## 1. 智能体总体架构

将智能体拆成 6 个模块，便于你后续迭代：

1. **输入解析模块**（接收你上传的视频）
2. **视频理解模块**（画面、动作、镜头节奏）
3. **音频理解模块**（BPM、段落、情绪起伏）
4. **文案分析与模板模块**（拆结构并输出可复用模板）
5. **素材搜集与筛选模块**（按规则找同类穿搭素材）
6. **生成与质检模块**（产出脚本+分镜+剪辑清单，并做质量评分）

推荐技术栈：

- 编排：LangGraph / AutoGen / 自建任务队列
- 视频处理：FFmpeg + OpenCV + PySceneDetect
- 音频分析：librosa / essentia
- 语音识别：Whisper（多语种）
- 文本生成：LLM（用于模板归纳、文案改写、镜头说明）
- 存储：PostgreSQL（结构化）、对象存储（素材）

## 2. 端到端工作流（你最关心）

下面是你要的“详细步骤”，可直接变成产品流程。

### Step 1：上传参考视频

用户输入：

- 参考视频 URL 或本地文件
- 目标平台（抖音/TikTok）
- 目标受众（例如：18-28 女性、偏辣妹风）
- 目标时长（15s / 30s / 45s）

系统动作：

- 下载并转码为统一格式（1080x1920，H.264，AAC）
- 抽帧（如 4fps）
- 抽取音轨

### Step 2：文案结构分析

系统先做 ASR（语音转文字），再做 NLP 结构化：

- 钩子句（前 1-3 秒）
- 痛点/场景
- 穿搭方案分点
- 强调词（“显瘦”“拉腿长”“高级感”）
- 结尾 CTA（“收藏照着穿”“评论区要链接”）

输出示例（结构 JSON）：

```json
{
  "hook": "腿短胯宽就照这套穿！",
  "problem": "小个子担心压身高",
  "solution_blocks": ["上短下长", "同色系拉伸", "配饰提重心"],
  "cta": "先收藏，周末逛街直接照抄"
}
```

### Step 3：背景音乐节奏分析

提取特征：

- BPM（节拍速度）
- Downbeat（强拍位置）
- 段落切换（主歌/副歌/Drop）
- 能量曲线（低→高）

产出：

- 一条时间轴（例如每 0.5s 一个节奏点）
- 推荐转场点（卡点位置）

### Step 4：视频节奏分析

分析维度：

- 镜头平均时长（ASL）
- 切镜频率（Cuts per 10s）
- 动作峰值（转身、甩发、走位）
- 画面元素密度（是否信息过载）

产出：

- 「镜头节奏画像」：例如“前 3 秒快切抓眼，中段稳定展示，结尾再加速”

### Step 5：自动搜集同类素材

按你的风格标签检索素材：

- 风格标签：性感辣妹 / 纯欲 / 欧美街头 / Y2K
- 场景标签：街拍 / 试衣间 / 室内镜前
- 动作标签：转身、走路、近景细节展示

筛选规则：

- 清晰度 >= 1080p
- 人物主体占比合理
- 无明显侵权 logo / 水印（或可裁切）
- 动作节奏可卡点

### Step 6：基于模板生成优化版脚本

将 Step 2 的结构模板和 Step 3/4 的节奏模板合并：

- 文案：保持“钩子→场景→方案→CTA”的骨架
- 画面：按节拍设置镜头长度（如 0.5s / 1s / 1.5s）
- 配乐：选择同 BPM 区间曲目
- 字幕：关键词加重（颜色、描边、放大）

输出三份核心结果：

1. **口播文案**（可直接念）
2. **分镜脚本**（每秒做什么）
3. **剪辑 EDL/指令**（给剪辑程序自动执行）

### Step 7：自动质检 + A/B 版本

至少生成 A/B 两版：

- A：快节奏高刺激（吸引停留）
- B：中节奏高信息（提升完播）

自动评分指标：

- 前 3 秒抓眼评分
- 节奏匹配评分（音画同步）
- 文案可懂度评分
- 合规风险评分

最终输出最高分版本 + 备选版本。

## 3. 你可以直接用的 Agent 提示词（系统 Prompt）

你可以把下面这段放到你的智能体系统提示中：

```text
你是一个短视频穿搭增长智能体。目标是根据用户提供的参考视频，提取文案结构、音乐节奏、视频节奏，并生成可发布的优化版穿搭解说方案。

必须执行：
1) 输出结构化分析（hook/problem/solution/cta）。
2) 输出节奏分析（BPM、强拍点、推荐切镜点）。
3) 输出30秒以内的分镜脚本（逐秒说明镜头、字幕、动作、转场）。
4) 输出A/B两个版本，并解释差异。
5) 严格执行平台与版权合规，不输出低俗、侵权或违规建议。

输出格式：
- 一、参考视频拆解
- 二、优化策略
- 三、A版分镜脚本
- 四、B版分镜脚本
- 五、剪辑执行清单
- 六、风险与合规提示
```

## 4. 后端任务编排（工程实现版）

可用一个异步流水线：

1. `ingest_job`：下载/转码/抽帧
2. `asr_job`：语音转写 + 分句时间戳
3. `audio_rhythm_job`：BPM + beat tracking
4. `video_rhythm_job`：切镜检测 + 动作峰值检测
5. `copy_structure_job`：文案结构抽取
6. `retrieval_job`：素材检索与打分
7. `generation_job`：脚本与剪辑清单生成
8. `qa_job`：合规审查与质量评分

建议把每个 job 的结果存成 JSON，方便可视化和复用。

## 6. 上线顺序（建议 3 个阶段）

1. **MVP（1-2 周）**：只做“参考视频分析 + 脚本生成”，人工剪辑。
2. **V2（2-4 周）**：加入自动素材检索、自动分镜和卡点建议。
3. **V3（持续）**：加入自动剪辑渲染、A/B 自动投放与数据回流优化。

1. 先确定一个垂类风格（例如“性感辣妹通勤穿搭”）。
